# Stormworks レーダー仕様

| 項目 | 値 / 式 |
|---|---|
| 探知可能最大距離 | `min(質量 / 250, 1) × 有効距離` |
| 探知間隔 (tick) | `floor(max((有効距離 / 2000) + 0.5, 1))` |
| 角度ノイズ | ±0.001 回転 |
| 距離ノイズ | 真の距離の 1% |
| チャフの質量 | 100,000 |
| チャフの探知条件 | 質量250以上かつ有効距離内 |

## 1. 探知距離とスキャン間隔

- **有効距離**: FOV設定値に依存。[§5](#5)で詳しく説明。
- **探知可能最大距離**: `min(質量 / 250, 1) × 有効距離`
  - 質量 ≥ 250 のオブジェクトは、有効距離の最大値まで探知可能。
- **探知間隔**: `floor(max((有効距離 / 2000) + 0.5, 1))`

## 2. ノイズ

探知中、前回の座標に対して以下の一様分布のノイズが加算され続ける。

- 水平・垂直: ±0.001 回転
- 距離: ±1%

## 3. チャフ（Chaff）

- 質量: 100,000
- 質量条件 (≥250) を満たすため、有効距離内では**ほぼ必ず探知される**。
- チャフの持続時間はおおよそ 359 tick（6秒）

## 4. レーダー5種と最大探知可能距離（FOV 0.01 / 0.01）

| レーダー | FOV 0.01/0.01 の最大探知可能距離 |
|---|---|
| Missile | 80 km |
| Basic | 240 km |
| Phalanx | 400 km |
| Dish | 800 km |
| AWACS | 2000 km |

## 5. 有効距離（最大探知距離）の計算式 {#5}

有効距離は FOV 設定値から以下の式で求められる。

```
maxRange ≈ baseRange / (fovX × fovY × 10000)
```

- `baseRange`: FOV が 0.01 / 0.01 のときの最大探知可能距離（上の表）
- `fovX` / `fovY`: 水平・垂直方向の FOV 設定値（turns）

## 6. コンポジット出力（Radar Data）

コンポジット出力は**最大8目標**まで、目標ごとに以下の4項目を連続したチャンネルで出力する。

- 距離（m）
- X方位・Azimuth（turns）
- Y仰角・Elevation（turns）
- 検出経過時間

目標 n の各データはチャンネル `(n−1)×4 + 1` 〜 `(n−1)×4 + 4` に割り当てられ、8目標 × 4項目 = **チャンネル1〜32** を使用する。

| 目標 | 距離 | X方位 | Y仰角 | 検出経過時間 |
|---|---|---|---|---|
| 1 | CH1 | CH2 | CH3 | CH4 |
| 2 | CH5 | CH6 | CH7 | CH8 |
| 3 | CH9 | CH10 | CH11 | CH12 |
| 4 | CH13 | CH14 | CH15 | CH16 |
| 5 | CH17 | CH18 | CH19 | CH20 |
| 6 | CH21 | CH22 | CH23 | CH24 |
| 7 | CH25 | CH26 | CH27 | CH28 |
| 8 | CH29 | CH30 | CH31 | CH32 |

- On/Off チャンネル1〜8 で各目標の検出有無（Target Found）を出力する。

## 7. レーダーに映るもの

- 人
- NPC
- 薬莢
- ビークル（マージ）
- 動物

## 8. レーダーのプロパティ

レーダーには以下のプロパティを設定できる。

| プロパティ | 説明 |
|---|---|
| Sweep Mode | 探索する方式 |
| Sweep Speed | レーダーの回転速度 |
| Sweep Limit | 扇型の探索範囲（0〜0.5回転） |
| Pitch Angle | 上下の向き（±0.12回転） |
| FOVX | X方向（水平）の視野 |
| FOVY | Y方向（垂直）の視野 |

### Sweep Mode（探索方式）

| モード | 探索方法 |
|---|---|
| Static | 前方のみを探索 |
| Clockwise | 時計回りにレーダーを回して探索 |
| Anticlockwise | 反時計回りにレーダーを回して探索 |
| Sweep | プロパティ「Sweep Limit」で決められた範囲を探索 |
| Manual | 外部からの複合信号で探索する向きを決定（上下0.125回転、左右は限界なし）。Missile レーダーにはない |

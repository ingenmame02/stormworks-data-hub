# Stormworks レーダー仕様

| 項目 | 値 / 式 |
|---|---|
| 探知可能最大距離 | `min(質量 / 250, 1) × 有効距離` |
| 探知間隔 (tick) | `floor(max((有効距離 / 2000) + 0.5, 1))` |
| 角度ノイズ | ±0.001 回転 |
| 距離ノイズ | 真の距離の 1% |
| チャフの質量 | 100,000 |
| チャフの探知条件 | 質量250以上かつ有効距離内 |

## 1. 探知距離とスキャン間隔

- **有効距離**: FOV設定値に依存。
- **探知可能最大距離**: `min(質量 / 250, 1) × 有効距離`
  - 質量 ≥ 250 のオブジェクトは、有効距離の最大値まで探知可能。
- **探知間隔**: `floor(max((有効距離 / 2000) + 0.5, 1))`

## 2. ノイズ

探知中、前回の座標に対して以下の一様分布のノイズが加算され続ける。

- 水平・垂直: ±0.001 回転
- 距離: ±1%

## 3. チャフ（Chaff）

- 質量: 100,000
- 質量条件 (≥250) を満たすため、有効距離内では**ほぼ必ず探知される**。

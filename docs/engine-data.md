# エンジンデータ集

ここでは、測定値を計算や比較に使いやすい係数へ整理しています。数値の単位は、特記しない限り Stormworks Torque（ST）と `dRPS / tick` に基づく正規化値です。

## 凡例

| 記号 | 意味 |
| --- | --- |
| ST | Torque Meter の値。回転慣性を含む測定値 |
| RPS | 1秒あたりの回転数 |
| dRPS | 1 tick あたりの RPS の差分 |
| 抵抗係数 | `dRPS × ST / RPS`。負の値は回転を減衰させる |
| 動力係数 | `dRPS × ST / Throttle`。スロットル1あたりの発生動力 |

## すぐに使える主要係数

| 部品・構成 | ST | 平衡係数 (RPS / Throttle) | 抵抗係数 | 動力係数 |
| --- | ---: | ---: | ---: | ---: |
| 小モーター単体 | 3 | 398.0007 | -0.00511166 | 2.03446 |
| 中モーター単体 | 3 | 398.0027 | -0.15334993 | 61.03369 |
| 既製小エンジン | 10 | — | -0.0511166 | — |


## モジュラーエンジンの抵抗

### 中サイズ

| 部品 | ST | 抵抗係数 |
| --- | ---: | ---: |
| 基本値 | — | -0.00511163 |
| クランクシャフト | 15 | -0.07667497 |
| ドライブベルト | 5 | -0.02555844 |
| シリンダー | 12 | -0.06133983 |

### 小サイズ

| 部品 | ST | 抵抗係数 |
| --- | ---: | ---: |
| 基本値 | — | -0.00511156 |
| クランクシャフト | 0.7 | -0.00357819 |
| ドライブベルト | 0.6 | -0.00306711 |
| シリンダー | 0.6 | -0.00306701 |

抵抗係数を `c`、RPS を `x` とすると、抵抗による正規化動力は概ね `c × x` です。複数部品を接続する場合は、基本値に各部品の係数を加算します。

## 負荷の抵抗曲線

| 負荷 | 抵抗の近似式 (RPS = x) |
| --- | --- |
| 鉱石ドリル（空転） | `0.9037x² + 5.1116x` |
| 鉱石ドリル（採掘） | `0.9037x² + 10.172x` |
| 小ジェネレータ | `0.0009128x²` |

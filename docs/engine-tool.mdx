# エンジン調整ツール

シリンダーとクランクシャフトのサイズ・個数、動力源、RPS、目標出力を入力すると、データ集の係数から空気スロットルと燃料スロットルの式を生成します。小シリンダー10個・小クランクシャフト5本の構成では、共有されたV10の2次測定モデルを使用します。小シリンダー8個・小クランクシャフト4本では、作成者から得た小V8の変換ルールを適用します。

<EngineThrottleTool />

## 式の読み方

一般モデルでは、データ集にある基本値・シリンダー・クランクシャフトの抵抗係数を個数分加算します。その抵抗を目標出力に加え、動力源の測定動力係数で割った式を生成します。燃料は空気量に過給補正を掛け、燃料比で調整します。

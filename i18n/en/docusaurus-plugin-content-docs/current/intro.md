# Welcome to Stormworks Data Hub

This site is a data hub for gradually organizing the mechanics and building methods of Stormworks.

## What to remember first

- Articles are placed in the `docs` folder.
- Headings are written with `#` and `##`.
- Notes can be written with `:::note` and warnings with `:::warning`.
- Site-wide names and menus are configured in `docusaurus.config.ts`.
